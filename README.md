# Video Game Tracker

A social platform for gamers to discover, track, and share their gaming experiences.

## Overview

This application allows users to:
- Browse and search for video games
- Rate and review games
- Comment and discuss games with other users
- Upload and share gameplay footage
- Track their gaming activity

## Tech Stack

- **Frontend**: React
- **Backend**: Node.js microservices architecture
- **Architecture**: Microservices for scalability and maintainability

## Features (Planned)

- Game pages with detailed information
- User authentication and profiles
- Rating and review system
- Community comments and discussions
- Gameplay video uploads and sharing
